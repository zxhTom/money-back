# 小程序端完整实现示例

## 文件结构

```
pages/
  callback/
    callback.js      # 页面逻辑
    callback.wxml    # 页面结构
    callback.wxss    # 页面样式
    callback.json    # 页面配置
```

## 1. callback.js - 核心实现

这是最重要的文件，包含 `handleWebViewMessage` 方法：

```javascript
// 接收 webview 发送的消息
handleWebViewMessage(e) {
  console.log('收到 webview 消息:', e);
  
  // 消息格式：{ data: [{ status, idNo, verifyToken }] }
  const messages = e.detail.data || [];
  const messageData = messages[0];
  
  if (messageData) {
    const { status, idNo, verifyToken } = messageData;
    
    if (status === 'success') {
      // 处理成功
      wx.showToast({ title: '操作成功', icon: 'success' });
      // 返回上一页
      setTimeout(() => {
        wx.navigateBack({ delta: 1 });
      }, 1500);
    } else {
      // 处理失败
      wx.showModal({
        title: '操作失败',
        content: '操作未完成，请重试',
        showCancel: true
      });
    }
  }
}
```

## 2. callback.wxml - 页面结构

关键点：`bindmessage="handleWebViewMessage"`

```xml
<web-view 
  src="{{webviewUrl}}" 
  bindmessage="handleWebViewMessage"
  binderror="handleWebViewError">
</web-view>
```

## 3. 在其他页面跳转到回调页面

```javascript
// 跳转到回调页面，传递参数
wx.navigateTo({
  url: '/pages/callback/callback?status=success&idCard=123456789&verifyToken=abc123'
});
```

## 4. 消息接收流程

1. **webview 页面加载** → 显示回调页面
2. **页面发送消息** → 调用 `wx.miniProgram.postMessage()`
3. **3秒后自动返回** → 调用 `wx.miniProgram.navigateBack()`
4. **触发 bindmessage** → 小程序收到消息
5. **处理消息** → 在 `handleWebViewMessage` 中处理

## 5. 消息格式

webview 发送的消息格式：
```javascript
{
  data: [{
    status: 'success',      // 或 'failed'
    idNo: '123456789',      // 身份证号
    verifyToken: 'abc123'   // 验证令牌
  }]
}
```

在 `handleWebViewMessage` 中接收：
```javascript
const messageData = e.detail.data[0];
const { status, idNo, verifyToken } = messageData;
```

## 6. 注意事项

1. **必须配置业务域名**：
   - 微信公众平台 → 开发 → 开发管理 → 开发设置
   - 在「业务域名」中添加你的服务器域名

2. **postMessage 触发时机**：
   - 消息不会立即触发
   - 只有在返回小程序时才会触发 `bindmessage`

3. **调试方法**：
   - 在 `handleWebViewMessage` 中添加 `console.log`
   - 在微信开发者工具中查看控制台输出
