# 微信小程序 WebView 回调配置说明

## 小程序端配置

### 1. 在页面中使用 web-view 组件

在你的小程序页面（如 `pages/callback/callback.wxml`）中添加 web-view 组件：

```xml
<web-view 
  src="{{webviewUrl}}" 
  bindmessage="handleWebViewMessage"
  binderror="handleWebViewError">
</web-view>
```

### 2. 在页面的 JS 文件中配置

在对应的页面 JS 文件（如 `pages/callback/callback.js`）中添加以下代码：

```javascript
Page({
  data: {
    webviewUrl: '' // 将在 onLoad 中设置
  },

  onLoad(options) {
    // 构建回调 URL，包含必要的参数
    const baseUrl = 'https://your-domain.com/api/mini/callback';
    const params = new URLSearchParams({
      status: options.status || 'success',
      idCard: options.idCard || '',
      verifyToken: options.verifyToken || ''
    });
    this.setData({
      webviewUrl: `${baseUrl}?${params.toString()}`
    });
  },

  // 接收 webview 发送的消息
  handleWebViewMessage(e) {
    console.log('收到 webview 消息:', e.detail);
    const data = e.detail.data[0]; // 获取消息数据
    
    if (data) {
      const { status, idNo, verifyToken } = data;
      
      // 处理回调结果
      if (status === 'success') {
        // 成功处理逻辑
        wx.showToast({
          title: '操作成功',
          icon: 'success'
        });
        // 可以跳转到其他页面或更新数据
        // this.handleSuccess(idNo, verifyToken);
      } else {
        // 失败处理逻辑
        wx.showToast({
          title: '操作失败',
          icon: 'error'
        });
        // this.handleFailed(idNo, verifyToken);
      }
      
      // 可选：返回上一页或跳转到指定页面
      setTimeout(() => {
        wx.navigateBack({
          delta: 1
        });
      }, 1500);
    }
  },

  // 处理 webview 加载错误
  handleWebViewError(e) {
    console.error('webview 加载错误:', e.detail);
    wx.showToast({
      title: '页面加载失败',
      icon: 'error'
    });
  }
});
```

### 3. 在 app.json 中配置业务域名

在 `app.json` 中添加 webview 的业务域名配置：

```json
{
  "lazyCodeLoading": "requiredComponents",
  "pages": [
    // ... 你的页面
  ],
  "permission": {
    "scope.userLocation": {
      "desc": "你的位置信息将用于小程序位置接口的效果展示"
    }
  },
  "requiredPrivateInfos": [],
  "navigateToMiniProgramAppIdList": [],
  "networkTimeout": {
    "request": 10000,
    "downloadFile": 10000
  }
}
```

**重要：** 你还需要在微信公众平台配置业务域名：
1. 登录微信公众平台
2. 进入「开发」->「开发管理」->「开发设置」
3. 在「业务域名」中添加你的服务器域名（如：`your-domain.com`）
4. 下载验证文件并上传到服务器根目录

### 4. 调用示例

在其他页面跳转到 webview 页面：

```javascript
// 跳转到 webview 页面
wx.navigateTo({
  url: '/pages/callback/callback?status=success&idCard=123456789&verifyToken=abc123'
});
```

## 注意事项

1. **postMessage 触发时机**：
   - `postMessage` 的消息不会立即触发，只有在以下时机才会触发 `bindmessage` 事件：
     - 小程序后退（navigateBack）
     - 小程序销毁
     - 小程序分享
   - 所以页面会自动尝试返回小程序，以确保消息能够送达

2. **消息格式**：
   - webview 发送的消息格式为：`{ data: [{ status, idNo, verifyToken }] }`
   - 在 `handleWebViewMessage` 中通过 `e.detail.data[0]` 获取

3. **自动返回**：
   - 页面会在 1.5 秒后自动尝试返回小程序
   - 用户也可以点击"返回小程序"按钮手动返回

4. **错误处理**：
   - 建议添加 `binderror` 事件处理加载错误
   - 在 `handleWebViewMessage` 中验证数据格式

## 测试步骤

1. 在小程序中打开包含 webview 的页面
2. webview 会加载回调页面
3. 页面会自动发送消息并返回小程序
4. 在 `handleWebViewMessage` 中接收并处理消息
5. 根据 status 显示相应的提示
