# 重名兼容灰度发布与回滚清单

## 1. 发布顺序

1. 发布后端（兼容接口）
2. 发布小程序与管理端
3. 执行数据库收敛脚本（仅在冲突清零后）

## 2. 关键灰度指标

- 登录失败率（按错误码分组）
- `AUTH_LOGIN_REALNAME_CONFLICT` 命中次数
- 注册成功率（按 `realname`、`idNo` 分组）
- 忘记密码成功率（`realname + idNo`）
- 合同 24 小时删除接口成功率

## 3. 功能验收点

- 同名不同身份证可分别注册和登录
- 输入唯一姓名可直接登录
- 输入重名姓名时返回“请补充身份证号登录”
- 输入身份证号可直接登录
- 删除 24 小时合同仅影响当前登录人身份证关联记录

## 4. 回滚策略

- 代码回滚：回滚后端与前端版本，保留数据库数据不动
- 数据库回滚：索引类变更采用“先停执行后回滚版本”，不回滚业务数据
- 应急开关：优先通过网关/发布平台回切旧版本，避免在线 DDL 回滚导致抖动
