# 管理员强制人脸认证

小程序「我的 → 强制人脸认证」，搜索并选择用户，点击「要求重新人脸认证」并确认。

`POST /custom/admin/face-auth/reset`，请求体 `{"username":"目标用户名"}`。
仅 `super_admin`、`tenant_admin` 可调用，服务层再次校验角色。所有查询和更新限定当前租户、未删除用户；用户名为空、不存在或不唯一会拒绝。

在事务中锁定目标记录，将 `system_users.verified` 固定设为 `0` 并更新时间；不提供设为已认证的参数。已是未认证的用户可重复操作。用户后续通过原有认证流程恢复认证；本操作不会立即弹出用户端摄像头，也不会注销会话。

验证：AdminFaceResetServiceTest 覆盖租户隔离、角色、无效输入和缺失/歧义用户。预环境与正式环境可能共用数据库，不对真实用户执行重置测试。
